# Обновление до VicDonationGoal 1.4.6

## Из 1.4.4 или 1.4.5.1

1. Сохраните старую папку целиком. Не распаковывайте новую версию поверх неё.
2. Остановите старую версию через её `13_STOP_ALL.bat`. Если уже запускали новую — остановите и её.
3. Распакуйте публичный архив 1.4.6 в отдельную новую папку.
4. Если Python и зависимости уже установлены, повторная установка обычно не нужна. На новом компьютере сначала выполните `00_INSTALL_ALL.bat`.
5. **До запуска `01_START_ALL.bat`** выполните из новой папки `16_UPDATE_FROM_OLD_VERSION.bat`.
6. В открывшемся окне выберите старую папку — ту, где находятся `VERSION`, `core` и `integrations`.
7. Дождитесь сообщения о завершении, затем запустите `01_START_ALL.bat` из новой папки. Откройте админку и сверьте историю, цель, топ и подключения.

Переносятся история, профили, корректировки, настройки и сохранённые авторизации. OAuth-токен может потребовать повторного входа, если сам сервис его уже отозвал или срок действия закончился. Перенос не может продлить такой токен.

Повторный перенос заменяет данные новой папки снимком выбранной старой версии; он не объединяет две разошедшиеся истории. Перед заменой создаётся резервная копия. Выбирайте правильную исходную папку.

Для Tribute теперь нужна ссылка из кнопки «Копировать ссылку для OBS». Старые настройки API/webhook сохраняются, но сами по себе нового подключения не создают. Ссылка Donatty переносится автоматически.

## Что происходит со старыми озвучками

Все уже импортированные донаты помечаются обработанными для TTS и Streamer.bot. Сохраняются также прежние отметки обработки. Незавершённая очередь TTS и команды воспроизведения в новой папке очищаются, чтобы старые сообщения не заговорили после обновления. Исходная очередь остаётся в старой папке и копии `backups/migration`.

Полученные, но ещё не записанные донаты Tribute в его собственной очереди не удаляются: это платежи, а не очередь озвучки.

Полный импорт через админку запрещён, пока работают внешние модули этой установки. Для обновления используйте способ выше. Импорт отдельного списка донатов в админке и раньше отключал автоматические озвучки для импортируемых записей.

## Чистая установка

Распакуйте публичный архив, выполните `00_INSTALL_ALL.bat`, затем `01_START_ALL.bat`. В админке пройдите настройку интеграций. В публичной папке нет истории, OAuth-токенов, личных ссылок и подключённых по умолчанию модулей. Streamer.bot и TTS включаются отдельно после настройки.

## Возврат

Остановите 1.4.6 и запустите сохранённую старую папку. При переносе она не изменялась. Донаты, пришедшие уже в 1.4.6, автоматически обратно не переносятся: сначала сохраните резервную копию новой версии. Одновременно две версии не запускайте — они используют один локальный порт и могут повторно обрабатывать события.

## Личная и публичная сборки

Архив с `_my_` и файл `PRIVATE_BUILD.txt` обозначают личную сборку с историей и секретами. Её нельзя публиковать. Для GitHub подготовлен отдельный публичный архив. Проверять нужно именно его после распаковки, а не настроенную личную папку.
