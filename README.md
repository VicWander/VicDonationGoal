# VicDonationGoal v1.4.6 — Reliability & Safe Update

Локальная система донат-гола, истории донатов, TopDonation, Streamer.bot events, TTS Hub и модульных интеграций донат-сервисов.

## Что нового в 1.4.6

Надёжность DonationAlerts и Donatty, прямое подключение Tribute по OBS-ссылке, защита файлов/импорта и перенос до запуска модулей. Полный список: `CHANGELOG_v1.4.6.md`. Переход из 1.4.4 и 1.4.5.1: `UPDATE_GUIDE.md` и `16_UPDATE_FROM_OLD_VERSION.bat` из новой папки.

## Что изменилось в v1.4.4

- новая главная сводка с отдельными лампочками системных модулей и донат-сервисов;
- Core Server, Integration Manager, Streamer.bot Bridge и TTS Hub отображаются отдельно;
- единый `source_registry.py` для всех источников донатов;
- единая модель состояний: connected / starting / degraded / error / stopped / disabled / unconfigured;
- безопасный диагностический ZIP без токенов и текстов донатов;
- расширенный `15_BETA_READINESS_CHECK.bat` с runtime-import и end-to-end проверками;
- исправлены склонения «донат / доната / донатов» и «донатер / донатера / донатеров»;
- Tribute подключается по OBS-ссылке без cloudflared и скрытого браузера;
- Tribute выключен по умолчанию и остаётся Experimental.

## Что изменилось в v1.4.4.1

- мастер первого запуска больше не сбрасывает выбранные интеграции во время фонового обновления;
- добавлена кнопка быстрого возврата наверх;
- подготовлена безопасная установка накопительных патчей с резервным копированием данных;
- roadmap разделён на перенос данных, Multi-Goal, кастомизацию, Desktop 2.0 и облачное восстановление.

## Что изменилось в v1.4.5

- полный резервный ZIP истории, TopDonation, цели, интеграций, токенов, Streamer.bot и TTS;
- восстановление и перенос данных из папки старой версии с проверкой схемы и контрольных сумм;
- импорт существующего `donations.json` без повторного добавления одинаковых записей;
- импорт стандартного `donations.xls` из DonationAlerts как обновляемого снимка TopDonation;
- автоматический бэкап текущего состояния перед любым применением;
- единая прокручиваемая страница донатов с быстрыми переходами к мониторингу, управлению, истории/TopDonation, состоянию и настройкам;
- единая прокручиваемая страница TTS Hub с быстрыми переходами между очередью, профилями, правилами, настройками, историей и логами;
- боковая навигация и доработанная горизонтальная компоновка админки.

## Что изменилось в v1.4.5.1

- состояния DonationAlerts разделены на OAuth/API, живой WebSocket, переподключение и ошибку, требующую действия;
- краткие обрывы сети больше не оставляют ложную красную ошибку после восстановления;
- после переподключения DonationAlerts безопасно догоняются пропущенные события без дублей и без массового импорта старой истории при первом запуске;
- в карточке DonationAlerts видны последнее подключение и результат догона;
- навигация TTS перенесена в левую панель и работает так же, как разделы донатов;
- счётчик Integration Hub учитывает только текущие предупреждения и ошибки, а не старые записи в логах.

## Быстрый запуск

```text
00_INSTALL_ALL.bat
09_STABILITY_CHECK.bat
15_BETA_READINESS_CHECK.bat
01_START_ALL.bat
```

Админка:

```text
http://127.0.0.1:3333/admin.html
```

Документация:

```text
http://127.0.0.1:3333/docs/index.html
```

## Диагностика

В админке нажмите «Диагностический отчёт» либо запустите:

```text
14_CREATE_DIAGNOSTIC_REPORT.bat
```

Отчёт сохраняется в `diagnostics/`, маскирует секреты и не включает тексты донатов.

## Готовность интеграций

```text
Stable:       DonationAlerts, Donatty, StreamElements, Donate.Stream, DonateX
Beta:         DonatePay, Streamlabs
Experimental: Tribute
```

## Размер сборки и Tribute

Для Tribute откройте интеграцию с OBS в мини-приложении, скопируйте персональную ссылку и вставьте в карточку Tribute. Cloudflare и API-ключ не требуются. Кнопка проверки и переключатель учёта событий описаны в `integrations/tribute/GUIDE.md`. Старый установщик cloudflared оставлен только для прежней webhook-схемы.

## Безопасность

Публичная сборка содержит чистые настройки. Личные данные появляются только после настройки или переноса. Не публикуйте свою настроенную папку; для распространения используйте исходный публичный архив.

Полные резервные копии также содержат эти секреты. Для обращения за поддержкой используйте диагностический ZIP, а не бэкап.
