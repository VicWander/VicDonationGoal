# DonatePay — v1.4.3

## Подключение

1. В кабинете DonatePay откройте раздел **API**.
2. Создайте личный API-ключ.
3. В Integration Hub откройте DonatePay, вставьте ключ, включите интеграцию и сохраните.
4. Нажмите **Проверить** или **Запустить**.

VicDonationGoal сам получает User ID через `/user`, затем подключается к официальному Centrifugo-каналу `$public:USER_ID`.

## HTTP 429 на `/transactions`

История транзакций используется только для восстановления событий, пропущенных во время отключения. В v1.4.3 ошибка `429 Too Many Requests` больше не ломает real-time подключение:

- catch-up временно пропускается;
- учитывается `Retry-After`, если DonatePay его прислал;
- повторные запросы к истории ограничены cooldown;
- WebSocket всё равно подключается и принимает новые донаты.

При необходимости можно выключить **«Восстанавливать пропущенные донаты через /transactions»**. Новые донаты продолжат работать.

API-ключ хранится локально. После публикации ключа где-либо перевыпустите его.
