# Подключение DonationAlerts

1. В кабинете DonationAlerts откройте раздел API Applications и создайте приложение.
2. Укажите Redirect URL точно: `http://127.0.0.1:3333/auth/donationalerts/callback`.
3. Скопируйте `Client ID` и `Client Secret` в настройки Integration Hub.
4. Сохраните конфигурацию.
5. Нажмите **Авторизовать** и разрешите доступ в DonationAlerts.
6. Вернитесь в Integration Hub и нажмите **Проверить**.

Проверка теперь отдельно показывает две части:

- **OAuth и API** — токен действителен, профиль и история доступны;
- **новые донаты** — живой WebSocket-канал подключён либо автоматически переподключается.

Краткий сетевой обрыв отображается жёлтым статусом **«Переподключение»**, а не красной ошибкой. Модуль сам увеличивает паузу между попытками и после восстановления проверяет последние страницы истории. Пропущенные донаты добавляются по их DonationAlerts ID, поэтому уже существующие события не дублируются.

При первом запуске v1.4.5.1 создаётся безопасная стартовая точка. Если последняя локальная запись найдена в свежей истории DonationAlerts, будут добавлены только события после неё. Если точка слишком старая, массовый импорт не запускается.

Используемые scopes:

- `oauth-user-show` — профиль пользователя;
- `oauth-donation-subscribe` — новые донаты в real time;
- `oauth-donation-index` — чтение донатов.

Client Secret и полученные токены являются приватными. Не публикуйте личную папку программы.
