# Подключение Donatty

1. В Donatty откройте настройку виджета для OBS.
2. Скопируйте обычную ссылку виджета и вставьте в поле **Ссылка OBS-виджета Donatty**.
3. Оставьте **Скрытый браузер** и **Автоматически получать SSE URL** включёнными.
4. Сохраните настройки и нажмите **Запустить** или **Проверить**.

Donatty выдаёт временную SSE-ссылку с JWT. Integration Hub запускает Playwright Chromium,
открывает страницу виджета и извлекает актуальную ссылку из сетевых запросов. После истечения
JWT модуль получает новый адрес автоматически.

Если автоматическое получение не работает, временно выключите скрытый браузер и посмотрите,
открывается ли страница виджета.
