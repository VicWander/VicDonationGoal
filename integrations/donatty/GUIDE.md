# Подключение Donatty

1. В Donatty откройте настройку виджета для OBS.
2. Скопируйте обычную ссылку виджета и вставьте в поле **Ссылка OBS-виджета Donatty**.
3. Оставьте **Автоматически получать SSE URL** включённым. **Использовать системный прокси** обычно должно быть выключено.
4. Сохраните настройки и нажмите **Запустить** или **Проверить**.

Для стандартной ссылки `https://widgets.donatty.com/donations/?ref=...&token=...`
модуль получает JWT через API виджета и подключается к SSE без запуска Chromium.
Используется тот же обмен токенами и тот же адрес потока, что в JavaScript самого виджета.
После истечения JWT модуль получает новый адрес автоматически.

Для старых ссылок, например мобильной страницы Donatty, и при несовместимости API
сохраняется резервный способ: Playwright открывает страницу и извлекает адрес потока
из сетевых запросов. Настройка **Скрытый браузер** относится только к этому способу.

Прямое подключение не меняет настройки VPN. Если VPN перехватывает трафик всего компьютера
через полный туннель, выключение системного HTTP-прокси само по себе этот туннель не обходит.
