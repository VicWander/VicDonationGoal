# Donate.Stream — v1.4.3

## Подключение

1. В кабинете Donate.Stream скопируйте полную ссылку alert-виджета вида `https://donate.stream/widget-alert?uid=...&token=...`.
2. Вставьте её в карточку Donate.Stream в Integration Hub.
3. Включите интеграцию, сохраните и нажмите **Запустить**.
4. Отправьте тестовое оповещение.

## Как работает

Виджет открывается в контролируемом Chromium. Donate.Stream передаёт события через Socket.IO / Engine.IO v4. Подтверждённый формат доната:

```text
42["alert", { ... }]
```

VicDonationGoal разбирает событие `alert`, использует `message_uid` как ID, а также получает `nickname`, `sum`, `message` и `currency`.

Повторные события фильтруются и после перезапуска.

Полная ссылка содержит приватный токен. Не публикуйте её.


## Прямое соединение при работе с прокси
По умолчанию встроенный Chromium работает через временный локальный HTTPS-мост Python. Это помогает, когда браузерные подключения перехватываются прокси, а Python имеет прямой доступ. Мост слушает только 127.0.0.1, живёт вместе с приёмником и не меняет настройки VPN. HTTPS проходит сквозным туннелем с проверкой сертификата. Полный системный VPN-туннель этот способ не отменяет.
Подключение считается установленным только после подтверждения Socket.IO. Отсутствие донатов не является ошибкой; потеря событий связи вызывает переподключение.
