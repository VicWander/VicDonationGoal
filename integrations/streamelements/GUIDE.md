# StreamElements

Интеграция использует официальный **Astro WebSocket Gateway** и подписывается на тему `channel.tips`.

## Что понадобится

- аккаунт StreamElements;
- Channel ID нужного канала;
- JWT Token или Overlay Token этого же канала.

Токены привязаны к выбранному профилю. Если к StreamElements подключено несколько Twitch/YouTube/Kick-аккаунтов, сначала переключитесь на нужный канал.

## Подключение

1. Откройте StreamElements Dashboard.
2. Нажмите аватар справа сверху и выберите нужный канал.
3. Скопируйте **JWT Token** или **Overlay Token**.
4. Найдите Channel ID выбранного канала.
5. В VicDonationGoal откройте **Интеграции → StreamElements**.
6. Вставьте Channel ID и токен.
7. Выберите правильный тип токена:
   - `jwt` — JWT Token;
   - `apikey` — Overlay Token;
   - `oauth2` — OAuth2 access token.
8. Включите интеграцию, сохраните настройки и нажмите **Проверить**.

## Как понять, что всё готово

Статус должен стать **Подключено**, а в логах появится строка о подписке `channel.tips`.

После этого сделайте маленький настоящий tip или доступное тестовое событие. Новый донат должен появиться в истории с источником `StreamElements`.

## Безопасность

JWT/Overlay Token даёт доступ к событиям выбранного канала. Не публикуйте его, не отправляйте в скриншотах и не загружайте личный config в GitHub.

## Типичные проблемы

### Successfully subscribed, но донаты не приходят

Проверьте, что Channel ID и токен относятся к одному и тому же выбранному каналу.

### Ошибка scope

Тема `channel.tips` требует право `tips:read`. Для личного JWT/Overlay Token канала обычно используется owner-доступ; OAuth2-токен должен иметь соответствующий scope.

### Событие пришло, но было пропущено

По умолчанию принимаются только `status=success` и разрешённые moderation states. Эти значения можно изменить в расширенных настройках интеграции.
