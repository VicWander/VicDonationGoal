# VicDonationGoal TTS Hub v1.2.1

TTS Hub — централизованная система озвучки донатов и внешних событий.

Она принимает текст, очищает его, выбирает правило и голосовой профиль,
маршрутизирует задачу в провайдер, хранит очередь, историю и технические логи.

## Рабочие провайдеры

- **Speaker.bot** — прямое подключение по WebSocket.
- **Microsoft Edge TTS** — генерация MP3 с воспроизведением через `/tts.html`.
- **Yandex SpeechKit** — облачный REST API.
- **XTTS Local** — подключение к отдельно запущенному локальному XTTS HTTP-серверу.
- **Custom HTTP** — универсальный адаптер к внешнему или локальному API.

## Основные файлы

- `tts_hub.py` — рабочий процесс TTS Hub.
- `tts_config.json` — локальные настройки.
- `tts_profiles.json` — голосовые профили.
- `tts_rules.json` — правила маршрутизации.
- `tts_queue.json` — очередь задач.
- `tts_history.json` — история обработки.
- `tts_log.json` — технические события.
- `providers/` — реализации провайдеров.
- `core/tts_hub_store.py` — хранение, нормализация и маршрутизация.
- `core/public/tts.html` — OBS Browser Source для аудиофайлов.

## Запуск

Обычный запуск всего проекта:

```text
01_START_ALL.bat
```

Только TTS Hub:

```text
08_START_TTS_ONLY.bat
```

Админка:

```text
http://127.0.0.1:3333/admin.html
```

Полный актуальный гайд находится в `docs/MANUAL.md` и доступен локально по адресу
`http://127.0.0.1:3333/docs/index.html`.

## Приватность

Рабочие конфиги могут содержать API-ключи, приватные URL, историю сообщений и
данные пользователей. Личную сборку нельзя публиковать без очистки.
