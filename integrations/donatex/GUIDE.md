# DonateX — v1.4.3

## Подключение через личный токен

1. В DonateX откройте **Настройки → API** и создайте External Token.
2. В Integration Hub откройте DonateX.
3. Вставьте токен.
4. Выберите режим **API polling**.
5. Способ передачи токена: **Query parameter**.
6. URL можно оставить пустым — используется официальный endpoint:

```text
https://donatex.gg/api/v1/donations
```

Программа запрашивает его с параметрами:

```text
skip=0&take=20&token=<ваш токен>
```

7. Сохраните, включите и нажмите **Проверить**.

При первом запуске существующие записи только запоминаются и не импортируются, если отдельно не включён импорт старой истории.

Если API вернул записи, но поля не распознаны, в техническом состоянии появится `responseShape` и `unrecognizedItems`. Тогда нужен обезличенный пример JSON без токена.
