# Первое оповещение без кода

- Запусти Streamer.bot. В Servers/Clients → HTTP Server оставь Host 127.0.0.1 и Port 7474, запусти сервер и включи Auto Start.
- В Actions создай действие, например «Оповещение о донате». Добавь через меню Sub-Actions воспроизведение звукового файла. Для картинки или текста подключи OBS в самом Streamer.bot и добавь нужные действия OBS. C# не нужен.
- Здесь укажи HTTP-адрес и нажми «Загрузить действия». Выбери созданное действие и сохрани настройки.
- Нажми «Проверить подключение»: эта кнопка ничего не воспроизводит. «Тестовое оповещение» запускает выбранное действие один раз; запись в историю и сумму сбора не добавляет.
- Включи интеграцию. Bridge запускается вместе с Core; отдельный запуск окна Bridge не нужен. При выключении интеграции новые оповещения не отправляются.

В текстовых полях поддействий Streamer.bot можно использовать %user%, %amount%, %currency%, %message% — имя, сумму, валюту и сообщение донатера. Для проверки поступают TestUser, 133 RUB и тестовое сообщение. Проверь готовое действие с нужными тебе поддействиями перед стримом.

ID надёжнее названия: после выбора из списка действие можно переименовать в Streamer.bot. Если создашь другое действие, выбери его заново. Список загружается из запущенного HTTP Server. Сначала сохраняй изменения, затем проверяй.

Озвучка через Speaker.bot настраивается отдельно: Озвучка → Настройки и провайдеры. Не добавляй повторную озвучку в Action, если сообщение уже читает TTS Hub.


## Оповещение по готовому примеру
В Гайдбуке открой «Оповещение о донате»: это полный путь от настройки OBS до теста, с готовым C#-кодом. Ссылка и раскрываемый пример с кнопкой копирования находятся на этой же странице Streamer.bot. Базовый вариант работает с цветной подложкой и текстами OBS без аудиофайла; звук подключается отдельно по желанию.
