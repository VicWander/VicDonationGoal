# История версий VicDonationGoal

Этот файл объединяет прежние отдельные changelog, release notes и инструкции к хотфиксам. Новые изменения добавляются сюда, а не в отдельные файлы в корне проекта.

## v1.4.6 — Reliability & Safe Update

Накопительное обновление после публичной 1.4.4: надёжность подключений, перенос данных и подготовка чистой установки.

## Подключения

- DonationAlerts: обработка нескольких JSON-сообщений в одном WebSocket-кадре, подтверждения подключения и heartbeat, явный выбор сетевого маршрута.
- Donatty: прямое получение SSE для стандартной OBS-ссылки без запуска браузера; устранена задержка коротких событий из-за буферизации; уточнены статусы и настройки прокси.
- Tribute: подключение напрямую по OBS-ссылке без Cloudflare и браузера, очередь доставки полученных событий, защита от дублей и проверочный режим с переключателем учёта.
- Завершившиеся процессы интеграций больше не остаются подключёнными по старому status-файлу.

## Данные и обновление

- Резервные копии, предпросмотр и проверка импорта, перенос из старой папки, защита от дублей и безопасный импорт таблицы DonationAlerts для топа.
- Исправлены выход за каталог public, небезопасные Windows-пути импорта, неполный откат и несогласованные резервные копии при изменении файлов.
- Новая команда `16_UPDATE_FROM_OLD_VERSION.bat`: перенос из остановленной старой версии в новую папку до запуска модулей.
- Старые донаты не озвучиваются и не запускают Streamer.bot повторно. Незавершённая очередь старой озвучки остаётся в исходной папке/бэкапе, но не запускается автоматически в новой.

## Админка

- Исправлено сохранение выбора интеграций при первичной настройке, улучшены навигация, мониторинг и разделы TTS.
- Цвет Tribute изменён на голубой; Donatty использует приглушённый фирменный градиент с вариантами для обеих тем.
- Встроенная инструкция Tribute и руководство обновления приведены к текущему подключению.

## Что учитывать

- Tribute пока Experimental. Проверен тестовый поток, включая два параллельных клиента; настоящий платёж и восстановление событий за время полного отключения требуют дальнейшей проверки.
- Tribute не передаёт признак теста. Переключатель учёта относится ко всем событиям в явно включённом двухминутном режиме. Вне этого режима учитываются все события.
- Настройка обхода HTTP-прокси не обходит VPN в режиме полного TUN-туннеля.
- Обновление выполняется в новую папку. Старая версия сохраняется для возврата; инструкция в `UPDATE_GUIDE.md`.


## v1.4.4 — Beta Readiness

Публичная закрытая бета. Релиз публикуется под тегом `v1.4.4`; исправления по результатам тестирования получают номера `v1.4.4.1`, `v1.4.4.2` и далее.

### Dashboard и статусы

- добавлена компактная сводка Core Server, Integration Manager, Streamer.bot Bridge и TTS Hub;
- донат-сервисы вынесены в отдельную сетку со статусами `connected`, `starting`, `degraded`, `error`, `stopped`, `disabled` и `unconfigured`;
- ошибки и предупреждения показываются выше работающих сервисов;
- добавлен переход из сводки в подробную карточку Integration Hub.

### Архитектура и надёжность

- добавлен центральный `source_registry.py` для всех автоматических источников;
- Streamer.bot Bridge и TTS Hub используют один реестр источников;
- manifests получили уровни готовности `stable`, `beta` и `experimental`;
- добавлены runtime-import, API, source-gate, JSON concurrency и end-to-end проверки;
- диагностический ZIP маскирует известные секреты и не содержит тексты донатов;
- `cloudflared.exe` исключён из релиза и скачивается только при включении Tribute;
- Tribute выключен по умолчанию.

### Интерфейс и релиз

- исправлены русские склонения количества донатов и донатеров;
- фильтры источников строятся из центрального реестра;
- подготовлен чистый первый запуск без токенов, истории, runtime и личных Action ID;
- README и внешний лендинг полностью переработаны под текущую версию;
- прежние разрозненные changelog и hotfix-файлы объединены в этот документ.
