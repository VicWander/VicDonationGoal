Оповещение о донате в Streamer.bot

Что получится

При донате в OBS появятся имя, сумма и сообщение на цветной подложке. Через 10 секунд оповещение скроется. Несколько донатов показываются по очереди. Базовый вариант не требует картинок, звуковых файлов и подписок: всё оформление собирается стандартными источниками OBS.

Гайд рассчитан на Windows, OBS Studio и Streamer.bot на одном компьютере. Заранее запусти оба приложения и VicDonationGoal. Первую настройку удобнее делать до трансляции: тест действительно покажет оповещение в OBS.

Подключить OBS к Streamer.bot

  1. В OBS открой Сервис → Настройки сервера WebSocket (Tools → WebSocket Server Settings). Включи сервер. В современных OBS он встроен; стандартный порт — 4455.
  2. Открой сведения о подключении в этом окне. В Streamer.bot перейди в Stream Apps → OBS, добавь подключение к 127.0.0.1 и перенеси порт и пароль из OBS. В некоторых версиях раздел называется OBS Studio.
  3. Включи автоматическое подключение, подключись и дождись состояния Connected. Запись и трансляцию для проверки запускать не нужно.

Код ниже использует первое подключение OBS: ObsConnection = 0. Если подключений несколько, выбери соответствующий индекс. HTTP Server на порту 7474 подключает VicDonationGoal к Streamer.bot; WebSocket на 4455 подключает Streamer.bot к OBS. Это разные соединения.

Собрать оформление в OBS

  1. Создай отдельную сцену с точным именем VDG Донат. Она будет прозрачным слоем поверх рабочей сцены; переключаться на неё во время стрима не потребуется.
  2. Добавь в неё Источник цвета, назови VDG Подложка. Например, выбери тёмно-серый цвет, размер 840 × 220 и небольшую прозрачность. Размести подложку там, где хочешь видеть оповещение.
  3. Добавь Текст (GDI+) с именем VDG Донатер. Впиши временно «Зритель — 133 ₽», выбери белый цвет, жирный шрифт и размер около 36. Включи собственные размеры текста, например 780 × 54, чтобы длинное имя оставалось в пределах подложки. Размести над подложкой с отступами.
  4. Добавь второй Текст (GDI+): VDG Сообщение. Впиши тестовую фразу, выбери размер около 26. В свойствах включи собственные размеры/границы текста и перенос слов: например, ширину 780 и высоту 130. Расположи под именем.
  5. В списке источников оба текста должны быть выше подложки. Можно добавить картинку, рамку и другие детали по своему вкусу. Не закрывай текст непрозрачным источником.
  6. Вернись в свою рабочую сцену с игрой/камерой. Добавь источник Сцена → VDG Донат и перемести его выше игры. Сохрани его имя VDG Донат. Подгоняй расположение источников в сцене оповещения под свой холст; приведённые размеры — пример для 1920 × 1080.
  7. Нажми на глаз рядом с вложенной сценой VDG Донат в рабочей сцене, чтобы скрыть оповещение до первого доната.

В коде поменяй MainScene = "Основная" на точное имя своей рабочей сцены. Остальные имена уже совпадают с шагами выше. Если используешь несколько рабочих сцен, добавь слой в нужную и настрой отдельный вариант действия под её имя; этот простой пример не переключает активную сцену сам.

Создать Action и очередь

  1. В Streamer.bot открой Actions & Queues → Queues, создай очередь Донаты и включи Blocking. Это заставляет следующий донат ждать окончания предыдущего. Не ставь длительное оповещение в общую очередь со всеми командами стрима.
  2. В Actions создай действие Оповещение о донате, назначь ему очередь «Донаты» и оставь действие включённым. Если есть параметр Concurrent, выключи параллельное выполнение.
  3. В Sub-Actions добавь Core → C# → Execute C# Code. Вставь весь пример из следующей главы вместо начального кода.
  4. Измени имя рабочей сцены в MainScene, нажми Compile и убедись, что ошибок компиляции нет. Сохрани код и действие. Отдельный триггер DonationAlerts добавлять не нужно: Action будет запускать VicDonationGoal.

Вид и расположение источников меняются в OBS. Код заполняет текст, показывает и скрывает сцену. Он не скачивает изображения, не создаёт сцены автоматически и не озвучивает сообщение через TTS.

Готовый код

Для начала достаточно заменить MainScene. Длительность задаёт DurationMs: 10000 — 10 секунд. SoundFile оставь пустым, пока не настраиваешь звук.

using System;
using System.Globalization;
using System.IO;

public class CPHInline
{
    // Замени только MainScene на имя своей рабочей сцены OBS.
    private const string MainScene = "Основная";
    private const string AlertScene = "VDG Донат";
    private const string HeaderSource = "VDG Донатер";
    private const string MessageSource = "VDG Сообщение";
    private const int ObsConnection = 0; // Первое подключение OBS в Streamer.bot.
    private const int DurationMs = 10000;

    // Необязательно: оставь пустым, и оповещение будет работать без звука.
    // Если добавишь путь, создай в сцене VDG Донат медиаисточник с этим именем.
    private const string SoundFile = @"";
    private const string SoundSource = "VDG Звук";

    public bool Execute()
    {
        bool sound = !string.IsNullOrWhiteSpace(SoundFile) && File.Exists(SoundFile);
        if (!string.IsNullOrWhiteSpace(SoundFile) && !sound)
            CPH.LogWarn("VDG: звуковой файл не найден. Показываю оповещение без звука.");

        try
        {
            CPH.ObsSetSourceVisibility(MainScene, AlertScene, false, ObsConnection);
            string user = Clean(GetArg("user", "Аноним"), 60);
            string amount = Clean(GetArg("amount", "0"), 30);
            string currency = Clean(GetArg("currency", "₽"), 10);
            string message = Clean(GetArg("message", "Спасибо за поддержку!"), 220);

            CPH.ObsSetGdiText(AlertScene, HeaderSource, user + " — " + amount + currency, ObsConnection);
            CPH.ObsSetGdiText(AlertScene, MessageSource, message, ObsConnection);

            if (sound)
            {
                CPH.ObsSetMediaSourceFile(AlertScene, SoundSource, SoundFile, ObsConnection);
                CPH.ObsSetSourceVisibility(AlertScene, SoundSource, true, ObsConnection);
            }

            CPH.ObsSetSourceVisibility(MainScene, AlertScene, true, ObsConnection);
            if (sound) CPH.ObsMediaRestart(AlertScene, SoundSource, ObsConnection);
            CPH.Wait(DurationMs);
            return true;
        }
        catch (Exception error)
        {
            CPH.LogError("VDG: оповещение не выполнено. Проверь подключение OBS и имена сцен/источников. " + error.Message);
            return false;
        }
        finally
        {
            try
            {
                CPH.ObsSetSourceVisibility(MainScene, AlertScene, false, ObsConnection);
                // Даём закончиться стандартному переходу скрытия до следующего доната.
                CPH.Wait(350);
                if (sound)
                {
                    CPH.ObsMediaStop(AlertScene, SoundSource, ObsConnection);
                    CPH.ObsSetSourceVisibility(AlertScene, SoundSource, false, ObsConnection);
                }
            }
            catch (Exception error)
            {
                CPH.LogWarn("VDG: не удалось скрыть оповещение или остановить звук. " + error.Message);
            }
        }
    }

    private string GetArg(string name, string fallback)
    {
        object value;
        if (!CPH.TryGetArg(name, out value) || value == null) return fallback;
        string text = Convert.ToString(value, CultureInfo.InvariantCulture);
        return string.IsNullOrWhiteSpace(text) ? fallback : text.Trim();
    }

    private string Clean(string text, int limit)
    {
        text = text.Replace("\r", " ").Replace("\n", " ").Trim();
        while (text.Contains("  ")) text = text.Replace("  ", " ");
        return text.Length > limit ? text.Substring(0, limit - 1) + "…" : text;
    }
}

Связать с VicDonationGoal и проверить

  1. В Streamer.bot открой Servers/Clients → HTTP Server. Запусти сервер на 127.0.0.1:7474 и включи Auto Start.
  2. В VicDonationGoal открой Интеграции → Streamer.bot. Оставь адрес http://127.0.0.1:7474/DoAction, если порт не менял.
  3. Нажми Загрузить действия, выбери «Оповещение о донате» и сохрани настройки. Привязка по ID продолжит работать после переименования Action.
  4. Проверить подключение только проверяет HTTP API и наличие действия. Затем нажми Тестовое оповещение: в OBS появятся TestUser, сумма 133 RUB и тестовое сообщение. История донатов и сумма сбора не изменятся. При ручном запуске Action без аргументов показываются «Аноним» и нулевая сумма — это нормально.
  5. Включи интеграцию Streamer.bot. Для обычного доната должен быть разрешён флажок отправки оповещения. Ручной донат тоже можно отправить в Action соответствующей галочкой.

При нескольких быстрых донатах очередь Blocking должна показать их по одному. Подтверждение HTTP означает, что Streamer.bot принял действие; правильность картинки, имён источников и звука проверяй в OBS.

Необязательно: добавить звук

  1. Выбери собственный аудиофайл, который можно использовать на твоей трансляции. Встроенного звука в этом примере нет.
  2. В сцене VDG Донат создай Медиаисточник с именем VDG Звук. Включи локальный файл, выбери аудио, выключи зацикливание. До проверки скрой этот источник.
  3. В коде заполни путь между кавычками в SoundFile = @"". Символ @ оставь: он позволяет вставить обычный Windows-путь без удвоения обратных слешей. Снова скомпилируй и сохрани.
  4. В микшере OBS проверь громкость медиаисточника. Чтобы слышать его самому, настрой устройство мониторинга и режим мониторинга в расширенных свойствах аудио. Режим «Только мониторинг» не отправляет звук зрителям; для звука и себе, и в трансляцию нужен «Мониторинг и вывод». Не захватывай тот же звук второй раз через устройство рабочего стола.
  5. Отправь тест. Звук запускается вместе с оповещением и останавливается при скрытии. Если файл не найден, визуальное оповещение продолжит работать без него. Чтобы снова убрать звук, очисти SoundFile и удали или скрой медиаисточник.

Сделать оформление своим

Меняй подложку, шрифты, размеры, положение и изображения в OBS, сохраняя имена двух текстов и сцены. Для плавного появления у источника вложенной сцены «VDG Донат» можно настроить переходы появления и скрытия «Затухание» примерно на 300 мс. Код оставляет 350 мс на завершение скрытия. Для более длинного перехода увеличь эту паузу.

В готовом примере сообщение ограничено 220 символами, имя — 60. Измени ограничения в вызовах Clean, если твоя композиция вмещает больше. Озвучка Speaker.bot остаётся в TTS Hub: не добавляй её второй раз в Action, если сообщения уже читаются программой.

Если не получилось

  • Действий в списке нет: проверь HTTP Server Streamer.bot и порт 7474. Сохрани Action и загрузи список заново.
  • Action принят, а картинки нет: проверь состояние подключения OBS, MainScene, наличие вложенной сцены VDG Донат именно в ней и видимость источников. Рабочая сцена должна быть той, которую ты смотришь. Глаз у текстов и подложки внутри сцены оповещения должен быть включён.
  • Текст не меняется: нужны источники Text (GDI+) с точными именами, а не текст в браузере или картинке. Выключи чтение из файла в свойствах текстов.
  • Оповещения перекрываются: проверь Blocking у отдельной очереди, назначение этой очереди Action и отсутствие параллельного выполнения.
  • Текст обрезается: увеличь область собственного размера текста или уменьши шрифт в OBS. Код специально ограничивает длину очень больших сообщений.
  • Нет звука: сначала настрой визуальный вариант, затем проверь путь, существование файла, имя медиаисточника, микшер и мониторинг OBS. Пустой SoundFile означает намеренно выключенный звук.
  • Ошибка Compile: скопируй пример целиком, проверь кавычки после редактирования и что C#-действие создано в Streamer.bot. Для диагностики открой журнал самого Streamer.bot.

Официальные справочники: очередь Blocking, ObsSetGdiText, HTTP Server, подключение OBS.
