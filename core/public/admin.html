Редактор правила

Что сюда вводить

eventType: donation, channel_reward, character, moderator_command, manual_test или своё значение.

source: donationalerts, donatty, manual, streamerbot, twitch, youtube, character-service или своё.

User ID, роли и Reward ID работают только когда их передал Streamer.bot или другая внешняя система. Пустое поле означает «любое».

Как это работает

Каждая интеграция приводит событие к единому формату VicDonationGoal. После этого Core одинаково обновляет историю, виджет, TopDonation, Streamer.bot и TTS.

Сервис → Integration Adapter → /api/donation
                     ↓
Core → Goal / History / Top / TTS / Streamer.bot
