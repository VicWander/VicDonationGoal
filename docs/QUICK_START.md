# VicDonationGoal 1.4.6 — быстрый запуск

## Уже пользовались 1.4.4 или 1.4.5.1?

Сначала откройте UPDATE_GUIDE.md в корне новой папки. Остановите обе версии и выполните 16_UPDATE_FROM_OLD_VERSION.bat из новой папки ДО запуска программы. Он перенесёт историю, настройки и авторизации, не запуская старые озвучки заново. Старую папку сохраните для возврата.

## Первая установка

1. Распакуйте публичный архив в отдельную папку.
2. Выполните 00_INSTALL_ALL.bat. Требуются установленный Python и доступ в интернет для загрузки зависимостей.
3. Выполните 01_START_ALL.bat и откройте http://127.0.0.1:3333/admin.html.
4. В разделе «Интеграции» выберите сервисы и заполните настройки по инструкциям карточек.
5. Для Donatty и Tribute вставляется персональная ссылка виджета для OBS. Для Tribute Cloudflare не нужен.
6. При необходимости отдельно включите и настройте Streamer.bot и TTS.
7. Остановите программу через 13_STOP_ALL.bat.

Полная инструкция: MANUAL.md. Личную настроенную папку с токенами и историей не публикуйте.
