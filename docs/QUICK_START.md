# VicDonationGoal v1.4.4 — быстрый старт

## 1. Что понадобится

- Windows 10 или 11;
- Python 3.11 или новее с включённой опцией `Add Python to PATH`;
- OBS Studio для виджета цели;
- интернет при первой установке зависимостей;
- аккаунт хотя бы в одном поддерживаемом донат-сервисе.

Streamer.bot, Speaker.bot и другие TTS-сервисы необязательны: устанавливайте их только для соответствующих функций.

## 2. Установка

1. Распакуйте архив в обычную папку, например `D:\VicDonationGoal`.
2. Не запускайте программу прямо из ZIP и не помещайте её в защищённую системную папку.
3. Запустите `00_INSTALL_ALL.bat`.
4. Дождитесь установки Python-пакетов и Playwright Chromium.
5. После сообщения `Done` запустите `01_START_ALL.bat`.

Установщик создаёт локальные конфиги из `*.example.json`. В публичной сборке нет чужих токенов, истории или готовых подключений.

## 3. Первый запуск

Откройте админку:

```text
http://127.0.0.1:3333/admin.html
```

В разделе `Интеграции` появится мастер:

1. выберите только тот сервис, который хотите настроить сейчас;
2. откройте его карточку;
3. заполните обязательные поля по встроенной инструкции;
4. сохраните настройки и нажмите `Запустить` или `Авторизовать`;
5. дождитесь зелёного статуса;
6. отправьте тестовый донат и проверьте его в истории.

Для первого теста лучше подключить один сервис. Остальные можно добавить позже в Integration Hub.

## 4. OBS-виджет

Добавьте в OBS источник `Браузер`:

```text
http://127.0.0.1:3333/widget.html
```

Рекомендуемый размер источника зависит от вашей сцены; начните с `1920 × 300`, затем подгоните CSS или трансформацию в OBS.

## 5. Streamer.bot и TTS

Эти модули можно оставить выключенными до тех пор, пока донаты и OBS-виджет не заработают стабильно.

- Streamer.bot настраивается в админке и в `integrations/streamerbot/README_DONATION_EVENT_RULES.md`.
- TTS Hub настраивается в одноимённом разделе; локальный проигрыватель доступен по адресу `http://127.0.0.1:3333/tts.html`.

## 6. Проверка установки

Запустите:

```text
09_STABILITY_CHECK.bat
15_BETA_READINESS_CHECK.bat
```

Предупреждение о выключенном или ненастроенном сервисе допустимо. Ошибки `ERR` нужно исправить до стрима.

## 7. Если что-то не работает

1. Закройте все окна через `13_STOP_ALL.bat`.
2. Повторно запустите `01_START_ALL.bat`.
3. Проверьте лампочки на главной странице админки.
4. Создайте диагностический ZIP кнопкой в админке или через `14_CREATE_DIAGNOSTIC_REPORT.bat`.
5. Свяжитесь с автором: [t.me/wander_streams](https://t.me/wander_streams).

Перед отправкой отчёта можно открыть ZIP и самостоятельно проверить его содержимое.
